# Torch & Tomb — 데모 / Demo

횃불이 꺼지기 전까지 커서를 대기만 하면 던전의 상자와 항아리, 어슬렁거리는 몬스터가 부서진다. 모은 동전으로 스킬 트리를 넓히고, 더 깊은 던전을 연다. 커서 약탈 인크리멘탈.

Hover your cursor and watch crates, jars and wandering monsters shatter before your torch burns out. Spend your haul on a sprawling skill tree and open ever-deeper dungeons. A cursor-looting incremental.

## 다운로드 / Download

[Releases](../../releases/latest) 에서 `TorchAndTomb_Demo_v0.2.0_win64.zip` 을 받는다.

Get `TorchAndTomb_Demo_v0.2.0_win64.zip` from [Releases](../../releases/latest).

## 실행 / How to run

1. zip 을 원하는 폴더에 압축 해제한다. / Extract the zip anywhere.
2. `TorchAndTomb.exe` 를 실행한다. / Run `TorchAndTomb.exe`.
3. Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행** 을 누른다(코드 서명이 없는 개인 개발 빌드라서 뜬다). / If Windows SmartScreen appears, click **More info → Run anyway** (the build is not code-signed).

요구 사양 / Requirements: Windows 10/11 64-bit.

## 데모 범위 / What's in the demo

- 던전 3곳: 마을 뒷산 무덤 · 청동 납골당 · 은빛 성골함실 / 3 dungeons: Hillside Graves · Bronze Ossuary · Silver Reliquary
- 스킬 노드 134개, 무기 7종, 유물 22종 / 134 skill nodes, 7 weapons, 22 relics
- 네 번째 던전부터는 정식판에서 이어진다. / The fourth dungeon onward is in the full game.

## 세이브 / Save data

데모 세이브는 정식판 세이브와 따로 저장된다. / The demo save is kept separate from the full game's save.
